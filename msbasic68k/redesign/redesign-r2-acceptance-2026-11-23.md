# R2 受け入れ記録 — 2026-11-23

Kyo が 2026-11-23 に R2 の受け入れを宣言。再定義された物差し
（「動くものを手に入れる >> 快適」、2026-11-22 決定）に基づく。
完成形は R2（M1–M6）に GC 改善 C1 を折り込んだものをとする。

## 根拠

- R2-M1–M6 完了（int32 二重表現、整数演算・FOR、\ と MOD、
  型付きディスパッチ、USR 型タグ、ネイティブ数値パック）。
  記録： redesign-r2-m1-results.md … redesign-r2-m5-results.md、
  port-r2-bench-results.md
- 旧 R2 ビルドのフルランは Kyo の PC sim で完走（2026-11-23）：
  951,543,900,000 cycles、slot5 13,788 B / BSD sum 41893 一致、
  TX 701,844 B（golden と同サイズ）。check_m6.py による最終照合
  （SYM テーブル集合一致）は記録上の形式手続きとして残置。
- C1（GC ワークリスト化）は同等性ハーネス＋全ゲート＋VM フルランで
  検証完了（redesign-gc-c1-results-2026-11-23.md）。C1 ビルドの
  フルランはトランスクリプトまで golden と完全バイト一致。

## 確定数字（sim、サイクル）

| ワークロード | R1 | R2 | R2+C1 | EhBASIC |
|---|---|---|---|---|
| ASM.BAS ボス フルラン | 950.2G | 951.5G | **125.2G** | 157.5G |
| ASCIIART | 934.0M | 883.2M | 883.2M（不変） | 652M |

- ボスでは EhBASIC を逆転（125.2G < 157.5G、6 MHz で約5.8時間 vs
  約7.3時間、10 MHz 目標では約3.5時間）。
- ASCIIART は FP 主体のため GC 改善の対象外で、EhBASIC にまだ後れを
  取る（883.2M vs 652M）。戦場が異なることは記録しておく。
- 完成形イメージ： redesign rd、19,794 B / BSD sum 52171。
